# 问象 · WeChat-Fortune-Fun

微信风格的奇门遁甲智能预测。起盘、智断联想、追问盘面，以及管理员后台。

排盘、十二类事项与区县天气模型来自 [wechat-Qimen-Divination-Service](https://github.com/Gideon-li/wechat-Qimen-Divination-Service)（本地 vendored 于 `vendor/qimen`）。事项与天气共用该区县一套权重；天气含奇门细述（天空、雨风雷雾、宜忌）。智断调用 qwen3.8-flash。

## 问事

- 微信授权登录（网页体验对应微信一键登录；也可手机号 / 邮箱，或 Google、X）
- 登录后用微信昵称建档；性别、出生年、城市可在对话里告诉问象
- 对话问事：直接说想问的事，或先随便聊聊。问象会从话里提取时间、事项和资料
- 看盘前会请你选测法：按此刻、指定时间、年/月/日运，或摇一个三位数求签。说「下个月运势」会按北京时间往后一个月起月运，不会去求签
- 闲聊时会安慰鼓励，并慢慢记住你的画像，之后的盘也会更贴你
- 智断一般在 500 字以内
- 一次预测扣 1 元（可买 1 / 10 / 30 / 88 次）；或 30 元月租畅问。永久免费由管理员开通。充值支持微信 / 支付宝
- 没有资料时会轻轻问一声；不愿意说就按通用盘来看
- 未提供准确位置时，只说方位和建筑类型，不报具体城市
- 超出当前盘的时间或事项时，会问要不要新开一盘；继续说预测意向则直接起
