# 问象

微信风格的奇门遁甲智能预测。起盘、智断联想、追问盘面，以及管理员后台。

排盘、十二类事项与区县天气模型来自 [wechat-Qimen-Divination-Service](https://github.com/Gideon-li/wechat-Qimen-Divination-Service)（本地 vendored 于 `vendor/qimen`，当前同步 `63695eb`）。事项与天气共用该区县一套权重，并走四柱×地盘（年看尊长主考、月看亲友、日看自己、时看顺逆）。天气含奇门细述（天空、雨风雷雾、宜忌）。智断调用 qwen3.8-flash。

## 问事

- 有微信就用微信进：唤起系统微信，或扫码在微信里打开后再授权，没有账号会直接注册。也可用 11 位手机号（密码）或邮箱验证码注册 / 登录
- 登录后用微信昵称建档；性别、出生年、城市可在对话里告诉问象
- 对话问事：直接说想问的事，或先随便聊聊。问象会从话里提取时间、事项和资料
- 看盘前会请你选测法：按此刻、指定时间、年/月/日运，或摇一个三位数求签。说「下个月运势」会按北京时间往后一个月起月运，不会去求签
- 网页端是左盘右话：点宫位会追问进对话；手动起盘也会在对话里写白话总断。点「智断这件事」会调用联想接口，结合你补的一句话写进对话框，之后还能继续追问。年/月/日运合成一条总看，原文用「看原文」展开。
- 闲聊时会安慰鼓励，并慢慢记住你的画像，之后的盘也会更贴你
- 智断一般在 500 字以内
- 一次预测扣 1 元（可买 1 / 10 / 30 / 88 次）；包月 30 元、包季 80 元、包年 288 元畅问。永久免费由管理员开通。充值出示微信 / 支付宝收款码，付完点「我已支付」即到账
- 没有资料时会轻轻问一声；不愿意说就按通用盘来看
- 未提供准确位置时，只说方位和建筑类型，不报具体城市
- 超出当前盘的时间或事项时，会问要不要新开一盘；继续说预测意向则直接起
